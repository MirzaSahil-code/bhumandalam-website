# Bhumandalam Seeds — Modern Storefront

This is a self-contained front-end redesign inspired by the current Bhumandalam Seeds store structure, with a more modern visual system and richer shopping interactions.

## Included
- Responsive desktop/tablet/mobile layout
- Hero landing page
- Crop category navigation
- Search + crop filter
- Product cards
- Local-storage cart
- Quantity controls
- WhatsApp order handoff
- FAQ accordion
- Sticky mobile navigation
- Direct phone/email/WhatsApp links

## Replace for production
1. Update the `products` array in `index.html` with the real catalogue, stock and prices.
2. Replace the demo seed-pack visuals with official product images.
3. Connect the WhatsApp link to the preferred order format/number.
4. Connect checkout to a payment/order backend and database.
5. Add an admin dashboard if live inventory and orders are required.

## Run locally
Open `index.html` directly in a browser, or use any static hosting provider.
